# ИНСТРУКЦИЯ ПО СБОРКЕ И ЗАПУСКУ


# Повышайка на 200 В

Запаиваем следующие элементы: `J1, U3, C8, R55, C9, L1, D8, C11, D7, Q12, R56, Q11, C10, R57, R58`.
Подключаем 12 В. На С11 долно быть около 200 В. Если есть, переходим к следующему шагу.


# Понижайка на 3.3 В

Запаиваем следующие элементы: `D6, C2, U2, C4, C5, R1, D1`. Подключаем 12 В. На C4 должно быть
3.3 В. Если есть, переходим к следующему шагу.
