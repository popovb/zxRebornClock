# ИНСТРУКЦИЯ ПО СБОРКЕ И ЗАПУСКУ


# Повышайка на 200 В

Запаиваем следующие элементы: `J1, U3, C8, R55, C9, L1, D8, C11, D7, Q12, R56, Q11, C10, R57, R58`.
Подключаем 12 В. На С11 долно быть около 200 В. Если есть, переходим к следующему шагу.


# Понижайка на 3.3 В

Запаиваем следующие элементы: `D6, C2, U2, C4, C5, R1, D1`. Подключаем 12 В. На C4 должно быть
3.3 В и горит D1. Если есть, переходим к следующему шагу.


# Микроконтроллер

Запаиваем: `U1, C1, J2, U4, R12-R15, D2-D5, Sw2-Sw6, R29-R33, R53, R54, J4`.

Идём сюда https://github.com/ch32-rs/wchisp/releases/tag/v0.3.0 и берём прошиватор
под нужную платформу. Как минимум паботает в Debian и Windows 10.

Плата обесточена. Зажимаем кнопку Download, подрубаем usb кабель к компу, отпускаем кнопку и
у нас несколько секунд, чтобы запустить прошиватор.

Для начала можно дать команду вывода информации чипа: `wchisp info`.
